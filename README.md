# SymbolicRegressionAirfoil

Symbolic regression project for the Airfoil Self-Noise dataset.

## Project idea

This repository focuses on discovering compact, interpretable mathematical expressions that can predict airfoil self-noise from the dataset features.

It is designed as a small 1–2 day project.

## What the project includes

- dataset loading and preprocessing
- baseline model comparison
- symbolic regression training and black-box comparation
- metric evaluation
- equation inspection and interpretation

## Dataset

The Airfoil Self-Noise dataset contains measurements of airfoil geometry and operating conditions, with the target representing the scaled sound pressure level.

Downloable at: https://archive.ics.uci.edu/dataset/291/airfoil+self+noise
